## 🚀 Como Executar o Projeto

### Pré-requisitos
- Python 3.x instalado
- Git instalado na máquina

### Passo a Passo

```bash
# 1. Clonar o repositório
git clone https://github.com/RafaelLimaJ/SENAC.git

# 2. Acessar o diretório do projeto
cd SENAC

# 3. Executar o script principal
python main.py
```
